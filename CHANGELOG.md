# CHANGELOG

## [1.31.60] — 2026-10-23

### Добавлено
- Система донатов DonateX с колёсом наград
- Мобы-призраки зрителей (`[Viewer]`)
- Boss Bar «Чат vs Стример»
- Scoreboard с отображением КД, кладбища и статистики
- Хаусмод (все КД отключены)
- Конструктор команд через GUI
- `/rules` — справочник команд в игре

### Изменено
- Локализация полностью переведена на русский и английский
- OAuth-токен маскируется в интерфейсе настройки
- Антиспам и whitelist вынесены в отдельный раздел безопасности

### Исправлено
- Все эффекты теперь выполняются строго на server thread
- Hardcore-guard корректно блокирует команды в хардкоре

## [1.10.1] — 2026-06-16

### Добавлено
- Базовая интеграция с Twitch IRC через twitch4j
- 45+ команд чата с префиксом `!`
- Конфиг через Cloth Config + Mod Menu
- Горячая клавиша `K` для открытия настроек
- `/twitchcraft connect|disconnect|reload|test|status`

### Исправлено
- Начальная стабильность подключения к Twitch-чату
